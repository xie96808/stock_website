# 结算页：遗憾值 + 炒股性格

结算页在收益率和按钮之间多一张卡：**遗憾值**（最优操作比你多赚多少）+ **炒股性格**（8 种打法标签）+ 一根从 0 弹到实际比例的红色量杆。「再来一局」旁带一句理由（如「补回这 18%」）。

## 数据与范围

- 全部在客户端算：结算页本来就有 30 根 K 线（`gameKline` 切出的对局窗口）和 29 个操作（`session.actions`），交给 `shared/reviewEngine.js`（付费「最优路线重演」用的同一套引擎）。
- 不请求服务端、不需要登录，**游客也能看到**（服务端复盘接口只给注册用户）。仅作展示：不影响结算、排名、奖励。
- 只在**经典局和韭币局（主页「开一局」）**显示（`gameKind` 为空、`classic` 或 `stake`，且没有下单次数上限；韭币局规则与经典局相同，最优路线一样）。一把梭、生存、每日挑战、残局最优的算法不同，不显示。窗口不完整或出错时只隐藏卡片，不影响结算页。

## 性格（顺序即优先级）

神仙盘感（拿到最优 80%+，且最优 > 0.5%）→ 空仓观众（一次没买；若最优本来就是空仓则为「稳扎稳打」）→ 钉子户（只买 1 次拿到最后）→ 追高侠（一半以上买入被标「追高」）→ 割肉达人（有「割在底部」）→ 卖飞选手（有「卖飞」）→ 手比脑子快（买入 ≥ 5 次）→ 稳扎稳打（其余，收益 ≥ −3%）。收益低于 −3% 的「其余」显示「摸索中」，避免亏很多还叫稳扎稳打。

## 遗憾值

最优收益 − 你的收益（百分点）。差不到 0.5 个点显示「几乎零遗憾」；这段行情怎么买都亏则显示「最优操作：空仓不动」，不出现「最优 +0%」。

## 控件

- 顶部「返回玩法选择 / 返回主页」固定在屏幕上（`#resultScreen > .sg-backbar` sticky，停在页眉带下方：桌面 58px、手机 62px），所以底部不再有「返回首页」。
- 「再来一局」居中、宽度 ≤ 300px，下面是「保存图片 / 排行榜」两个轻量入口。

## 动画

结果页出现约 0.6 秒后开始：量杆带过冲地从 0 弹到实际比例，红色数字同步计数；量杆当时还在屏幕外（小屏手机），滑入屏幕时再弹一次。`prefers-reduced-motion` 下直接显示最终值。拿到 0% 时量杆保持空（末端的墨线用内阴影画，宽度为 0 时不显示）。
