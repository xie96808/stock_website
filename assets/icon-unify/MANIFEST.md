# icon-unify · 阶段 1 素材清单（韭币 coin + 后悔券 stub）

输出目录：`/workspace/assets/icon-unify/`。每个素材 4 个文件：`name.png`(@1x)、`name@2x.png`、`name.webp`、`name@2x.webp`（@1x/@2x 均由 SVG 原生渲染，非缩放；WebP 为无损，与 PNG 在 alpha>0 处逐字节一致）。
全部 14 个素材 × 4 = 56 个文件，合计 55886 字节（≈54.6 KB）。生成可复现（两次生成 md5 完全一致）。无烘字、无颗粒/斑点/飞白、透明底、居中；币为方形画布，后悔券 15×17 槽位版为竖长画布（见 §3）。

## 1. 现网韭币图标几何（已对照 PLAN.md 与真实代码核实）
来源：`js/jiu-coin.js coinIconHtml()` + `css/jiu-coin.css`（origin/main @50c91fc），实测盒子来自 `before/bboxes.json`。
- SVG viewBox **24×24**；CSS 盒：`.jiu-coin-icon{width:.95em;height:.95em;overflow:hidden;display:block;flex-shrink:0}`（SVG 的 size 参数被忽略，盒子完全由 em 决定）。
- 内容：淡色圆盘 **r=10**（fill #1f6b3a opacity .18，唯一占到 r10 的元素，四周留白 2/24）；外环 r8.2 描边 1.6（**外缘 r=9**）；内环 r5.2 描边 1.2；¥ 形笔画（stroke 1.35）。
- 颜色：亮色 `#1f6b3a`；暗色 `#7dcea0`（`[data-theme="dark"] .jiu-price-badge.jiu-price-paid .jiu-coin-icon` 等）；暗色余额条仍是 #1f6b3a 外环 + `rgba(61,184,106,.12)` 底。
- 实测盒子边长（CSS px）：9.5（价签/药丸，10px 字号）、11.39（顶部余额条，12px）、12.16、12.45、13.06、13.97、14.44（反悔按钮里的价钱）、15.19（确认弹窗）、15.95（领取成功弹窗）。
- 外缘基准：新图“外侧墨色轮廓外缘”落在 **r = 10/24 × 盒边**（0.41667·盒边；12px 画布 5.00px，14→5.83，16→6.67，20→8.33，24→10.00）。注意：现网“看得见”的实线外环外缘是 r9，淡圆盘 r10 才是足迹；新图按你的要求对齐到 r10，视觉上比旧外环大约 1/24 盒边（≈0.4–0.7px）；没有任何东西超出 r10（无外投影）。
- 居中方形画布，圆心 = 画布中心，换图后盒子/行高/布局零变化（`_swap-sim.png`：用真实截图换图，图标盒之外 0 个像素变化）。

## 2. 韭币图标（`coin-glyph-{12,14,16,20,24}` + `-dark`）
设计 = `lw-prize-1` 单枚韭币：牛皮纸贴纸圆盘 + 墨色描边 + #1f6b3a 韭币字形（¥ 形笔画）+ 淡绿 wash；**去掉了斜转与右下硬投影**（投影会越过 r10）。字形色与现网一致 #1f6b3a。
参数（24 单位盒，1 单位 = N/24 px；描边外缘固定在 r=10）：

| 尺寸 | 墨描边宽 | 外环(r, 宽) | 内环 | 字形缩放/笔宽 | 说明 |
|---|---|---|---|---|---|
| 12 | 2.5 | 无 | 无 | ×1.18 / 2.3 | 极简：粗轮廓 + 粗字形 + 淡绿底，9.5px 下仍清楚 |
| 14 | 2.3 | 无 | 无 | ×1.14 / 2.1 | 同上 |
| 16 | 2.0 | (6.7, 1.5) | 无 | ×0.84 / 1.8 | 加外环 |
| 20 | 1.6 | (7.1, 1.4) | 无 | ×0.88 / 1.6 | 近完整 |
| 24 | 1.2 | (7.3, 1.4) | (4.8, 1.0) | ×0.88 / 1.4 | 完整（≈ lw-prize-1 缩小版） |

- **day（亮）**：贴纸 #f3ead8，描边墨 #3a3530。
- **night（暗，`-dark`）**：贴纸 #efe5cf，描边暖褐 #8f7f63（墨描边在暗底会消失，改浅描边让外缘仍清晰；外缘位置与 day 完全相同）。字形仍 #1f6b3a。适用：暗页 #1c1a16、暗卡 #242018、暗余额条 #202d20、暗价签 #283b26、领取钮 #1a3324。
- **使用提示（重要）**：暗色主题下“弹窗卡片、反悔按钮/确认弹窗”仍是牛皮纸底（实测 #ede4d3 / #f5eee1），这些位置应当用 **day** 版（现网这里暗色图标 #7dcea0 浅绿落在牛皮纸上对比度很差）。night 版只给真正深色的底。

## 5. 自检结果（`_verify.py` → `_verify-report.txt`）
- 外缘半径对齐：见 §2。
- 散点：56 个 PNG 的透明度连通域数均为 1（无散点）；无颗粒、无飞白（纯矢量平涂，笔宽均匀）。
- 边界 alpha：所有素材四周边缘 alpha = 0（币有 2/24 留白，票根 ≥1px 透明边）。
- WebP 与 PNG 在 alpha>0 处逐字节一致；透明像素已 bleed（无灰/白边）。
- 已逐张 Read：`_contact-sheet.png`（由下列分表拼成）、`_check-bg-day.png`、`_check-bg-night.png`、`_check-bg-ticket.png`、`_check-9.5px-legibility.png`（12 号在 9.5/11.4px、DPR1/2，与旧图并排，x6）、`_overlay-alignment.png`、`_swap-sim.png`（真实截图 before|after x4）、票根 @2x 1000% 放大图。

## 6. 已知问题 / 备注
1. 对齐到 r10 意味着新币比现网“可见外环”(r9) 大约 1/24 盒边；若想与旧外环视觉大小完全一致，改成 r9 只需改一个参数。
2. 1× 屏上 12/14px 的墨描边是亚像素宽度，会有一圈灰阶抗锯齿（9.5px 盒子 DPR1 尤其明显）；@2x 清晰。已用尽量粗的描边（12px: 1.25px）。
3. 后悔券带 -10° 微倾，1× 下边缘有抗锯齿灰阶（同 item-ticket-16 风格）；要 1× 绝对锐利可改 0°，需你定。
4. 后悔券 15×17 票根实占约 11×11.5px，视觉重量比旧文字 ↩ 大；撕口虚线在 15px 下很淡（刻意，避免糊）。
5. night 币用浅褐描边而非墨描边（墨色在暗底会消失）；设计取舍，外缘位置不变。
6. 没有改任何站点代码、没有部署；`_swap-sim.png` 只是在 before 截图上的像素模拟。
