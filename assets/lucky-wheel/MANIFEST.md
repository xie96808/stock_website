# 幸运转盘 (Lucky Wheel) asset kit — `/workspace/assets/lucky-wheel/`

Style lock: ctl-buy v3 (kraft `#f3ead8`, ink `#3a3530`, cinnabar `#e05252`, green `#3db86a`, hard offset shadow). **No baked text or numbers anywhere** (labels/amounts/titles are CSS 楷体). Transparent PNG `@1x` + `@2x` (master) + WebP of each. Generated by `_gen_lw.py` (+`_lw_lib.py`), deterministic (seeded, re-run gives byte-identical files). Assets only — **no site code changed, nothing deployed.**

**Rev 3 (DESIGN §4.10):** `lw-face` is now transparent ink line-art (no fills; CSS paints the 8 wedge colours underneath) and the jackpot pack is exactly four files: `lw-jackpot-rays`, `lw-coin-sprite-atlas`, `lw-popup-jackpot-banner`, `lw-rim-light` (old coin-rain / sparks / crown / halo-frame removed).

Hand-made feel is limited to **line-width variation and slight outline wobble on large pieces** (face, rim, ribbon, card, prize art). There is **no grain, speckle, dry-brush or hatching anywhere**. Controls (`lw-hub-*`, `lw-go-*`, `lw-close-*`) are flat fills + perfectly uniform 2–2.6px ink strokes + hard offset shadow.

## 1. Sector order convention (READ THIS before writing CSS/JS)

* Angles are measured in **degrees clockwise from 12 o'clock (the pointer)** — same direction as CSS `rotate()`.
* The pointer is at 0° (top). At rest (disc rotation 0°) **sector 0 is centred under the pointer**: it straddles the pointer and spans −22.5°…+22.5°. Sectors are numbered **clockwise**: sector *k* is centred at **45·k°**.
* **Sector boundaries are exactly at 22.5° + k·45°** (22.5, 67.5, 112.5, 157.5, 202.5, 247.5, 292.5, 337.5). So the *first boundary clockwise from the pointer* is 22.5° (= right edge of sector 0). Rim pegs sit on the same angles.
* To land on sector *k* with jitter *j* ∈ [−13°, +13°]: final disc rotation `θ = 360·n − (45·k + j)` (CSS `rotate(θ deg)`, clockwise positive).
* Place label *k* at `rotate(45·k deg) translateY(-r)` inside the rotating disc (design doc Table A positions = these sector numbers; jackpot 888 = sector 5).

## 2. Geometry / anchors / slicing — what CSS needs

* **`lw-face` 360×360 — transparent ink line-art only (no fills)**: outer ring (centre line r 174, ink to 176.5), thin inner ring r 162, 8 hand-drawn dividers **exactly on 22.5°+k·45°** (measured ±0.1°) running r 44→174, centre ring r 44 (outline only). Rotation axis = canvas centre (180,180) (verified: bbox & centroid offset 0.00 px). Put it inside the 400-px stage at `inset:5%`; paint the wedge fills (CSS above) *under* it inside the same rotating `.lw-disc`; icons/labels in CSS on top.
* **`lw-rim` 400×400** — static, centre (200,200). Ring r 174→193 (inner hole r=174 is exactly centred; face covers it). 8 pegs at r 183.6, angles 22.5°+k·45° (verified ±0.02°). Hard shadow 3 px to bottom-right is part of the art.
* **`lw-pointer` 56×72** — pivot (pin centre) at **(28,17)** → `transform-origin: 28px 17px` (50% 23.6%). Tip at (28,67). Recommended placement in the 400 stage: tip on the rim/face edge at r≈168 → pointer box top-left at (172, −35) (i.e. it sticks 35 px above the stage). Flick = rotate about the pin.
* **`lw-hub-*` 96×96** — button centre (48,48); ring r 41 + hard shadow (2.6 px default, 1 px press). Centre it on the stage centre. `spinning` has three kraft arc segments (may be CSS-rotated about the canvas centre).
* **`lw-go-*` 280×64** — body rect (4,4)–(272,58), pill; shadow 3 px (press: art nudged +2,+2 and shadow 1 px → no CSS translate needed). `loading` has a kraft arc spinner at x≈38; start the label at x≈62 in that state. Blank label zone x 60…248.
* **`lw-close-*` 40×40** — disc centre (20,20); hit area 44 px is CSS.
* **`lw-glow` 360×360 (NOT 180×180)** — the 45° highlight wedge is drawn on the *same canvas as `lw-face`* pointing UP (= sector 0). Rotate it about the canvas centre by `45·k°` to cover sector *k* (so no off-centre transform-origin maths). Put it between the face and the number labels.
* **`lw-flash` 256×256 / `lw-jackpot-rays` 512×512** — exact centred squares, axis = centre; 8 / 16 spikes so they loop seamlessly at 45° / 22.5° steps.
* **`lw-ribbon` 360×84** — blank red centre for the title, x ≈ 116…244 at y 8…64 (kraft text `#f3ead8` + 1.5–2 px ink text-stroke; kraft on `#e05252` is only 3.2:1 plain, so keep the stroke).
* **`lw-tag` 160×32** — 9-slice **12 px** all sides (`border-image-slice: 12 fill` @1x; `24` for the @2x file).
* **`lw-result-card` 320×380 (prize pop-up card, 「获得奖品」)** — kraft card, red ribbon straddling the top edge, blank centre, no text.
  * **9-slice cut lines (1× px): top 78, right 56, bottom 44, left 56.** (`@2x` file: 156 / 112 / 88 / 112.)
  * Why: top 78 = ribbon + tails + shadow; left/right 56 = card border + ribbon tails/folds (all x < 52); bottom 44 = corner + hard shadow. The middle column (x 56…264) of the top band is flat red + a 1.3 px rule, so it can stretch horizontally; the middle row is plain border, so it can stretch vertically. Minimum width ≈ 232 px (recommended 320).
  * CSS: `border-style:solid; border-width:78px 56px 44px 56px; border-image: url(lw-result-card@2x.png) 156 112 88 112 fill / 78px 56px 44px 56px stretch;` — content box = the blank middle. Title text sits on the ribbon at y≈4…60 (centre x = card centre).
* **`lw-jackpot-rays` 512×512** — gold radial rays, 16 spikes (long/short alternating), soft radial fade; axis = canvas centre; rotate slowly behind the pop-up (loops seamlessly every 22.5°).

Coin centre = cell centre. Loop 0→5 then back 5→0, or flip frame 0 horizontally for the 180° pose. `ctx.drawImage(atlas, i*80, 0, 80, 80, …)` on the @2x file.
* **`lw-popup-jackpot-banner` 320×142** — gold ribbon + crown, blank title zone (x 52…268, y 72…116, ink text). Same x-grid and ribbon shape as `lw-result-card`; place with top = card top − 62 px so it exactly covers the red ribbon (ribbon panel y 66…122 vs 4…60 in the card).

Same canvas as `lw-rim` (overlay, axis = centre). 16-fold symmetric, so a rotating conic mask (or opacity chase) gives the 追光 effect; with the overlay hidden the rim is its normal self.

## 3. 韭币 coin = the balance-chip coin

The coin on every 韭币 asset (`lw-prize-1…5`, `lw-coin-sprite-atlas`) is the **exact glyph of `coinIconHtml()`** in `js/jiu-coin.js` / `.jiu-coin-icon` in `css/jiu-coin.css`: 24-unit viewBox, 18 % wash disc r10, ring r8.2 (1.6), ring r5.2 (1.2), the stroked ¥-like glyph path, colour `#1f6b3a` — copied verbatim into `_lw_lib.COIN_GLYPH`. **Only addition:** a kraft `#f3ead8` sticker disc (r 10.7) with a 0.95-unit ink outline *behind* it, because the original is a pale wash that disappears on coloured sectors. The glyph itself is not redrawn.

* `lw-prize-ticket-2` = fanned pair, `-3` = fanned stack of three, each stub carries a hand-drawn **↩** (hook-arrow) like `#rewindBtn`'s glyph; the “×2/×3” text is CSS.
* Added `lw-entry-icon-16/24` **and** `-dark` variants (kraft strokes for the dark-green dark-theme pill); red dot = CSS.
* Pointer/hub/close/go carry a baked hard offset shadow (style lock), so their *visible* bounding box is shifted ≤ 3 px to the bottom-right; the geometry (hub ring, pin, disc) is exactly centred on the canvas centre.
* The ribbon title colour contrast is 3.2:1 for plain kraft on `#e05252` — use the ink text-stroke (fine for 20 px+ title).
* Sector order/colours are now the §4.10 list (青瓷 … 松绿); the earlier rainbow palette is gone. Because `lw-face` has no fills, its dividers are the only thing that must stay at 22.5°+k·45° — the colour wedges are exact by construction in CSS.
* Dropped per the §4.10 change: coin-rain variants, sparkle stars, crown/halo frame (the crown survives only inside the banner).
* The “888” chest is the only prize art that uses non-palette colours (warm brown wood + gold straps); coins in it are the real 韭币 glyph.
* Not integrated or tested in the page (no site code touched): CSS wiring, real-device look, and Android WebView WebP decoding are for the client batch.
* Re-run: `cd /workspace/assets/lucky-wheel && python3 _gen_lw.py && python3 _verify.py && python3 _preview.py && python3 _make_manifest.py` (needs Pillow, numpy, scipy, cairosvg; ≈1.5 min).
